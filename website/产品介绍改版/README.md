## 上线方式

1. 快速方式：把两份文件覆盖到线上 `assets/` 目录下同名文件（文件名保持不变，HTML 无需改动）。
2. 正规方式：把以下改动回移到 Vue 源码后重新构建：
   - 步骤数据数组（原 `AI通识/工作诊断/部门共创/智能体落地`）换成上表 5 项，并加 `lane: entry | core | aux` 字段；
   - 路径图模板（根节点 `div.method-path.method-path-v3`）：`div.core-bracket > p.group-label`（核心产品括注）→
     `article.path-step.path-entry`（01）→ 3 × `article.path-step.path-core.is-featured`（02–04）→
     `span.aux-drop`（虚线）→ `aside.path-step.path-escort.path-aux`（内含 `p.group-label` 辅助产品 + 05 内容）；
   - 样式：见 CSS 文件末尾 `/* ===== 产品介绍 · 路径图 v3 ===== */` 之后的全部规则；
   - 导航项、SectionHeading 的 kicker/title/description、场景页脚 meta 文案同步更新。
